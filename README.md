# Faculdade

Objetivo do projeto
O objetivo deste projeto é desenvolver uma Calculadora Multifuncional utilizando o Flowgorithm, aplicando os conceitos de lógica de programação estudados durante o curso de Engenharia de Software.

O programa possui um menu principal com 11 opções. As 10 primeiras opções correspondem a funções de cálculo escolhidas pelo grupo, enquanto a 11ª opção é utilizada para encerrar o programa.

A calculadora permanece em execução enquanto o usuário desejar realizar novos cálculos. Após a realização de cada operação, o programa retorna automaticamente para o menu principal. O encerramento acontece somente quando o usuário seleciona a opção 11.

Para o desenvolvimento do projeto foi utilizado o Flowgorithm.

O Flowgorithm é uma ferramenta que permite criar e executar algoritmos por meio de fluxogramas. A ferramenta foi utilizada para representar visualmente a lógica da calculadora e facilitar a compreensão da sequência de execução do programa.

Ao iniciar o programa, o menu principal é apresentado ao usuário com as 11 opções disponíveis.

O usuário deve escolher uma das opções digitando o número correspondente à operação desejada.

Após a escolha, o programa utiliza estruturas de decisão para identificar qual operação deve ser executada.

Quando uma função de cálculo é selecionada, o programa solicita os dados necessários, realiza o cálculo e apresenta o resultado na tela.

Depois de apresentar o resultado, o programa retorna automaticamente para o menu principal. Dessa forma, o usuário pode realizar uma nova operação sem precisar executar o programa novamente.

Esse processo continua até que o usuário selecione a opção 11, correspondente a "Encerrar".

Caso o usuário informe uma opção que não esteja entre 1 e 11, o programa apresenta uma mensagem informando que a opção é inválida e retorna ao menu principal.

O arquivo do Flowgorithm foi publicado no repositório por meio de um commit, registrando a versão desenvolvida para a atividade.

O desenvolvimento da Calculadora Multifuncional permitiu aplicar na prática os conceitos de lógica de programação estudados durante o curso de Engenharia de Software.

Durante o projeto foram utilizados conceitos como variáveis, estruturas de decisão, estrutura de repetição While, entrada e saída de dados e operações matemáticas.

A utilização do Flowgorithm também possibilitou visualizar melhor o funcionamento do algoritmo por meio do fluxograma, facilitando a compreensão da sequência de execução do programa.

Além de desenvolver as funções matemáticas, foi necessário pensar no funcionamento do menu, no retorno automático após cada operação e no tratamento de opções inválidas.

Dessa forma, o projeto contribuiu para o desenvolvimento dos conhecimentos básicos necessários para a criação de programas mais completos futuramente.
